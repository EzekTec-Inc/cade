Enterprise Boundaries, Groups & Landscape View Syntax

Enterprise Boundary Syntax

model {
    // 1. Enterprise Scope (Internal Systems)
    enterprise <name> {
        systemA = softwareSystem "Internal System A" "Description"
        
        // Optional Domain Sub-grouping
        group "Operations" {
            systemB = softwareSystem "Internal System B"
        }
    }

    // 2. External Scope (Third-Party Systems / SaaS / Partners)
    externalSaaS = softwareSystem "External SaaS Provider" "Description"
}

Landscape View Syntax

views {
    systemLandscape <viewKey> [description] {
        include *                  // Include all people and systems
        // OR selective includes:
        // include systemA externalSaaS customer

        autoLayout [tb|bt|lr|rl]   // Direction of auto-layout routing
    }

    theme default
}

Visual Rendering Behavior

Construct Visual Representation
enterprise "Name" { ... } Dashed rectangular boundary enclosing all internal systems and personas with the enterprise name banner.
group "Domain" { ... } Inner grouping box clustering related systems (e.g. Sales, Core Banking, Data Lake).
External systems (outside enterprise) Rendered outside the enterprise boundary box with distinct shading (gray by default).
