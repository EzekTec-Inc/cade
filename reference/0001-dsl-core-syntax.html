Structurizr DSL Core Syntax & Landscape Cheat Sheet

Top-Level Hierarchy

workspace [name] [description] {
    model {
        // Elements and relationships live here
    }
    views {
        // Diagrams and styling live here
    }
}

Core Element Declarations

Keyword Syntax Description
person id = person <name> [desc] [tags] Human user or actor
softwareSystem id = softwareSystem <name> [desc] [tags] Standalone software system
-> (relationship) src -> dst [desc] [tech] [tags] Unidirectional relationship

Landscape View Definition

views {
    systemLandscape <key> [description] {
        include *
        autoLayout [tb|bt|lr|rl]
    }

    theme default
}

Common Gotchas

  • Identifiers (left of =) must be unique within their scope and contain no whitespace.
  • Strings containing spaces must be enclosed in double quotes ("...").
  • include * renders all systems and people in the workspace.
  • autoLayout instructs the layout engine to arrange elements automatically (options: tb top-bottom, lr left-right).
