# Teaching Notes & Learner Preferences

## Learner Profile
- **Starting Level**: Complete beginner to C4 modeling and Structurizr DSL syntax.
- **Primary Goal**: System Landscape and Reference Architecture design.
- **Style Preference**: Step-by-step, clean visual artifacts (Tufte style), concrete code examples, and immediate interactive feedback loops.

## Pedagogical Principles Applied
- Focus on **Storage Strength** over fleeting fluency (retrieval practice with balanced quiz options).
- Ground every syntactic element in why an architect needs it in a landscape diagram.
- Provide clean reference cards alongside each lesson for long-term retention.
