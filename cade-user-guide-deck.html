Up & Running in 3 Minutes

Zero complex dependencies. Single binary installation with automated local database initialization.

STEP 01
Launch CADE
Start the interactive agent terminal or launch the background daemon:
cade
# or start daemon:
cade-server
STEP 02
Configure Provider
Connect your preferred LLM (Anthropic, OpenAI, Gemini, Ollama):
/connect anthropic
/model claude-3-5-sonnet
# or use local Ollama models
STEP 03
Run Your First Task
Point CADE at any task, refactor, bug, or feature:
"Refactor auth middleware to use JWT bearer tokens"
